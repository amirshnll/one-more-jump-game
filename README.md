# One More Jump

## Short description

Run, jump, collect coins, and survive for as long as possible.

## Description

One More Jump is a lightweight, multilingual endless-platformer browser extension. Players cross procedurally generated platforms, avoid hazards, collect coins, and try to improve their best distance and score.

## Purpose

The extension delivers a compact arcade experience that can be launched instantly from the browser toolbar for quick, replayable gaming sessions.
